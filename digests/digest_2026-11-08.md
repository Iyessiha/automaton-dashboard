## 1. StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference
*Relevance: 242%*

StrataFlux solves the accuracy-speed tradeoff in quantized LLM inference by selectively streaming higher-precision refinement data from host RAM and SSDs, recovering accuracy lost to low-bit weight and KV cache quantization without sacrificing memory and speed benefits. This matters to ML practitioners because it enables deploying large models with quantization's efficiency gains while mitigating quality degradation, making host memory hierarchy a practical resource for precision recovery during inference.

→ http://arxiv.org/abs/2611.08363v1

## 2. SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
*Relevance: 233%*

**Summary:**

SwarmEvolve addresses the inefficiency of LLM-guided evolutionary search, where generating lengthy text-based reasoning for diverse populations is computationally slow. The method uses hundreds of lightweight agents that reason directly in latent space (avoiding text decoding) and share information through KV cache passing, enabling faster parallel exploration.

This matters to ML practitioners because it significantly reduces the computational cost of AI-driven program synthesis and optimization while maintaining population diversity, making evolutionary discovery more practical for mathematical and computational problems.

→ http://arxiv.org/abs/2611.08483v1

## 3. Benchmarks as Software: Terminal-Bench and the Case for Continuous Benchmarks
*Relevance: 223%*

This paper addresses **benchmark maintenance debt**—the problem where coding benchmarks become unreliable over time as models discover valid solutions that verifiers incorrectly reject and infrastructure changes invalidate test assumptions. The authors introduce **Terminal-Bench with continuous validation**, treating benchmarks as evolving software that requires ongoing maintenance rather than static artifacts, ensuring evaluation accuracy keeps pace with rapidly improving coding agents.

→ http://arxiv.org/abs/2611.08417v1

## 4. Measured Coupling for Parallel Decoding in Diffusion Language Models
*Relevance: 220%*

This paper solves the problem of efficiently deciding which tokens can be safely decoded in parallel during diffusion language model generation, replacing the existing mean-field proxy (which penalizes similar-looking predictions) with direct measurement of token coupling—how committing one token affects model confidence at other positions—using cheap probes within the forward pass. For ML practitioners, this matters because the method requires no additional training or auxiliary models, integrates with existing decoding rules, and achieves faster generation with fewer steps across multiple models and benchmarks.

→ http://arxiv.org/abs/2611.08307v1

## 5. AutoCompress: Automated Hardware-Guided Model Compression
*Relevance: 219%*

AutoCompress solves the problem of LLM pruning workflows that target parameter counts rather than actual hardware constraints (latency, throughput, memory), which poorly predict real-world performance across different architectures, workloads, and GPUs. The method uses differentiable architecture search that directly incorporates hardware-specific constraints, enabling automated model compression that meets practical deployment requirements—eliminating manual trial-and-error for ML practitioners who need compressed models optimized for their specific serving environments.

→ http://arxiv.org/abs/2611.08290v1
