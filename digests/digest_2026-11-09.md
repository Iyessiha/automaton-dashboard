## 1. BitDecoding-FP4: Native FP4 KV Cache Decoding via Algorithm-System Co-Design
*Relevance: 261%*

**Summary:** BitDecoding-FP4 solves the trade-off between accuracy and efficiency in 4-bit KV cache quantization for long-context LLM serving, where existing approaches either suffer accuracy drops (vanilla FP4) or throughput degradation (codebook-based methods). Through algorithm-system co-design, it enables native FP4 KV cache decoding that maintains accuracy while leveraging FP4 Tensor Cores, which matters for ML practitioners deploying memory-constrained long-context LLMs at scale.

→ http://arxiv.org/abs/2611.09825v1

## 2. FOSCAR: Accelerating Decode Attention over 2- and 4-Bit KV Caches through Affine Folding
*Relevance: 242%*

FOSCAR solves the latency bottleneck in low-bit (2-4 bit) KV cache quantization for LLM decode attention, where existing kernels achieve poor GPU throughput (under 31% on H100) due to the overhead of dequantizing each cached value before computation. The method uses "affine folding" to apply quantization scales and offsets to the query/output tensors instead of KV values, dramatically reducing instruction overhead and enabling faster Tensor Core utilization—this matters to ML practitioners because it unlocks actual speedups from memory-efficient KV cache compression during LLM inference.

→ http://arxiv.org/abs/2611.09722v1

## 3. A Tight Hierarchy for Chain of Thought
*Relevance: 235%*

This paper proves the first hierarchy theorem for chain-of-thought (CoT) reasoning, demonstrating that giving transformers more CoT steps strictly increases their computational power—specifically, that CoT with r(n)^(1+ε) steps can solve problems impossible for CoT with only r(n) steps. For ML practitioners, this provides theoretical justification for scaling CoT length, confirms that longer reasoning chains aren't just empirically useful but fundamentally expand model capabilities, and establishes rigorous complexity-theoretic foundations for understanding when and why extended reasoning helps.

→ http://arxiv.org/abs/2611.09759v1

## 4. CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse
*Relevance: 233%*

**Summary:** This paper addresses the inefficiency of LLMs repeatedly solving similar problems from scratch by introducing Agentic Reasoning Caching (CPU-ARC), which converts LLM reasoning traces into reusable, CPU-executable caches that can be applied to new problem instances without further LLM involvement. This matters to ML practitioners because it enables significant computational savings and efficiency gains by separating one-time reasoning from repeated execution, achieving comparable performance to frontier LLMs on mathematical tasks while dramatically reducing inference costs.

→ http://arxiv.org/abs/2611.09891v1

## 5. On Agentic Manipulation Policies
*Relevance: 232%*

This paper addresses the challenge of reliable robot manipulation by demonstrating that generalist AI models (agentic manipulation policies) can outperform specialist approaches like vision-language-action models when directly commanding manipulators with adaptive, real-time action adjustment. For ML practitioners, this matters because it suggests that leveraging powerful generalist foundation models with appropriate harnesses like AMP1 may be more effective than training specialized manipulation policies, potentially simplifying deployment across diverse robotic platforms (single-arm, bimanual, mobile) while achieving state-of-the-art performance.

→ http://arxiv.org/abs/2611.09892v1
