## 1. Beyond Causal Masks: Auditing and Localizing Hidden Future-Token Leakage in Adaptive Sequence Models
*Relevance: 233%*

**Summary:**

This paper addresses the problem of hidden future-token leakage in autoregressive models, where architectural components (like adaptive routing mechanisms) can inadvertently expose the model to future tokens despite correct causal masking, creating misleadingly good evaluation metrics that don't translate to actual generation quality. The authors develop a prefix-invariance audit method to detect and localize such leakage, which matters to ML practitioners because it reveals how architectural innovations can produce illusory gains that only appear during teacher-forced evaluation while degrading real-world autoregressive generation performance.

→ http://arxiv.org/abs/2610.31522v1

## 2. Training Small Language Models for Transferable Tool Selection
*Relevance: 227%*

This paper addresses the challenge of selecting relevant tools from large tool corpora for LLM agents, where existing retrieval methods fail to identify which tools are actually needed for complex instructions. The authors demonstrate that small, open-source language models can be trained via reinforcement learning to match the tool selection performance of proprietary LLMs like Claude or ChatGPT, offering ML practitioners a more accessible and cost-effective solution for building tool-using agents.

→ http://arxiv.org/abs/2610.31483v1

## 3. Causal Chain of Thought: Mitigating Attention Leakage via Context Isolation
*Relevance: 218%*

This paper addresses the problem of chain-of-thought reasoning steps being post-hoc justifications rather than causally driving model answers, caused by attention leakage where models can bypass reasoning through direct context lookup. The authors introduce CausalCoT, an inference framework that decomposes problems into directed acyclic graphs of atomic sub-questions with isolated context evaluation, ensuring each reasoning step genuinely contributes to the final answer—which matters to ML practitioners seeking more faithful, interpretable, and trustworthy reasoning from language models.

→ http://arxiv.org/abs/2610.31639v1

## 4. EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence
*Relevance: 217%*

**Summary:**

EpiSEM-Bench addresses the problem of LLM agents executing unsafe actions when tool responses omit safety-critical facts, even when all returned information is technically true. The benchmark introduces 300 matched unsafe/safe task pairs across six domains, systematically suppressing critical evidence to evaluate agents' unsafe execution rates and evidence recovery capabilities.

This matters to ML practitioners because it reveals a fundamental safety vulnerability in tool-using agents—decisions made with incomplete rather than incorrect information—providing a systematic framework for testing and improving agent robustness in real-world deployment scenarios.

→ http://arxiv.org/abs/2610.31650v1

## 5. Questioning Instrumental Convergence in RLVR: Checkpoint Evidence from OLMo-3
*Relevance: 217%*

This paper investigates whether reinforcement learning with verifiable rewards (RLVR) causes large language models to develop instrumental convergence behaviors like self-preservation, deception, or power-seeking, using checkpoint analysis from OLMo-3 training. For ML practitioners, this matters because it provides empirical evidence about whether standard RLVR post-training introduces dangerous agentic tendencies, informing safety evaluations and training pipeline decisions.

→ http://arxiv.org/abs/2610.31624v1
