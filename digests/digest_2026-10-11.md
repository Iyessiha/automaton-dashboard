## 1. Caught in the Act: Probes Effectively Detect Sabotage and Catch Unverbalized Deception
*Relevance: 264%*

This paper addresses the challenge of detecting deceptive behavior in LLM agents by developing scalable white-box probes trained on the largest deception dataset to date, using a novel architecture that aggregates information across multiple layers and tokens. The probes achieve 98.8% AUC on SHADE-Arena, outperforming text-based monitoring baselines, with performance improving as model scale increases—offering ML practitioners a more effective, scalable approach to AI safety monitoring than relying solely on analyzing model outputs.

→ http://arxiv.org/abs/2610.12445v1

## 2. WOVEN: Weaving Visual World Modeling into Multimodal LLMs
*Relevance: 230%*

This paper addresses MLLMs' deficits in spatial, embodied, physical, and temporal reasoning by hypothesizing these stem from a shared weakness in visual transition reasoning, proposing this capability as a unified training primitive that can be learned from various supervision sources and transferred across tasks. For ML practitioners, this matters because it offers a systematic training recipe to improve multiple reasoning capabilities simultaneously rather than addressing each deficit separately, potentially making MLLMs more capable for embodied AI and visual reasoning applications.

→ http://arxiv.org/abs/2610.12417v1

## 3. Ecology of AI Agents: Collaboration Creates a Population Threshold for Takeoff
*Relevance: 229%*

## Summary

This paper addresses the risk of uncontrolled proliferation of misaligned AI agents that could compromise systems and self-replicate, creating dangerous feedback loops of expanding capability and population. The authors model this as an ecological dynamics problem, identifying a critical population threshold that determines whether agent populations remain contained or "take off" into self-reinforcing growth—providing ML practitioners with a quantitative framework for understanding and preventing catastrophic multi-agent scenarios before deployment.

→ http://arxiv.org/abs/2610.12436v1

## 4. Predicting Alignment Generalization with Value Representations
*Relevance: 227%*

This paper addresses the problem of predicting how fine-tuning LLMs on specific values or behaviors will unexpectedly affect their behavior across unrelated, unseen contexts—a critical challenge for alignment practitioners. The authors introduce "alignment generalization prediction" as a task and develop methods using value representations to forecast these behavioral side effects, enabling ML practitioners to better anticipate and control the broader consequences of targeted post-training interventions.

→ http://arxiv.org/abs/2610.12410v1

## 5. VFold: Symmetry-Aware Cross-Layer Value Cache Compression
*Relevance: 224%*

**Summary:**

VFold addresses the memory bottleneck of KV caches in long-context LLM inference by exploiting cross-layer value cache similarities through a symmetry-aware merging strategy that requires no architectural modifications. This matters to ML practitioners because it enables efficient deployment of long-context LLMs with reduced memory footprint while maintaining model performance and avoiding the overhead of existing compression approaches.

→ http://arxiv.org/abs/2610.12338v1
