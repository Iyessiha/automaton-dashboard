## 1. StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference
*Relevance: 239%*

StrataFlux solves the accuracy-versus-speed tradeoff in low-bit LLM quantization by selectively streaming higher-precision refinement data from host RAM and SSDs, recovering accuracy lost to aggressive weight and KV cache quantization without sacrificing memory and latency benefits. This matters to ML practitioners because it enables deploying highly compressed LLMs with improved accuracy by leveraging existing memory hierarchies, making efficient inference more accessible without requiring expensive hardware upgrades.

→ http://arxiv.org/abs/2611.08363v1

## 2. SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
*Relevance: 233%*

**Summary:**

SwarmEvolve addresses the inefficiency of LLM-guided evolutionary search by replacing costly text-based reasoning with hundreds of lightweight agents that reason directly in latent space and share information via KV caches, dramatically reducing computational overhead while maintaining population diversity. This matters to ML practitioners because it enables faster, more scalable evolutionary optimization for program synthesis and mathematical problem-solving without sacrificing the benefits of LLM-guided search.

→ http://arxiv.org/abs/2611.08483v1

## 3. AutoCompress: Automated Hardware-Guided Model Compression
*Relevance: 221%*

AutoCompress solves the problem of LLM pruning workflows that target parameter counts rather than actual hardware constraints (latency, throughput, memory), which poorly predict real-world performance across different architectures, workloads, and GPUs. The method uses differentiable architecture search that directly incorporates hardware-specific constraints, enabling automated model compression that meets practical deployment requirements without manual trial-and-error by ML practitioners.

→ http://arxiv.org/abs/2611.08290v1

## 4. Benchmarks as Software: Terminal-Bench and the Case for Continuous Benchmarks
*Relevance: 219%*

This paper addresses "benchmark maintenance debt"—the problem where coding benchmarks become unreliable over time as improving models find valid solutions that verifiers incorrectly reject, and infrastructure changes invalidate test assumptions. The authors introduce Terminal-Bench with a continuous-validation approach, treating benchmarks as evolving software rather than static datasets, which matters to ML practitioners because unreliable benchmarks lead to misleading capability assessments of economically important coding agents.

→ http://arxiv.org/abs/2611.08417v1

## 5. Measured Coupling for Parallel Decoding in Diffusion Language Models
*Relevance: 218%*

This paper solves the problem of efficiently determining which tokens can be safely decoded in parallel during diffusion language model inference, replacing the proxy-based mean-field approach with direct measurement of token coupling (how committing one token affects confidence at another position) using cheap probes within the forward pass. For ML practitioners, this method requires no additional training or auxiliary models, integrates with existing decoding frameworks, and achieves faster inference with fewer steps across multiple benchmarks—making parallel decoding in diffusion LMs more practical and efficient.

→ http://arxiv.org/abs/2611.08307v1
