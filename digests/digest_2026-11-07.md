## 1. StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference
*Relevance: 246%*

StrataFlux addresses the tradeoff between accuracy loss from low-bit quantization and latency stalls from offloading higher-precision data in LLM inference, by co-designing refinement representation, selection, and delivery to selectively stream additional precision from host RAM and SSDs. This matters to ML practitioners because it enables recovering quantization-induced accuracy degradation while maintaining the memory and speed benefits of low-bit inference, making efficient LLM deployment more practical without sacrificing model quality.

→ http://arxiv.org/abs/2611.08363v1

## 2. SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
*Relevance: 230%*

**Summary:**

SwarmEvolve addresses the slow, expensive nature of LLM-guided evolutionary search by replacing text-based reasoning with hundreds of lightweight agents that reason in latent space and share information via KV caches, eliminating costly text decoding. This matters to ML practitioners because it dramatically accelerates evolutionary optimization and program synthesis while reducing computational costs, enabling more efficient automated discovery for mathematical and computational problems.

→ http://arxiv.org/abs/2611.08483v1

## 3. Benchmarks as Software: Terminal-Bench and the Case for Continuous Benchmarks
*Relevance: 224%*

This paper addresses benchmark maintenance debt—the problem where coding benchmarks become unreliable over time as models discover valid solutions that verifiers incorrectly reject and infrastructure changes break evaluation assumptions. The authors introduce Terminal-Bench with continuous validation, treating benchmarks as evolving software rather than static artifacts, which matters to ML practitioners because stale benchmarks produce misleading capability measurements for economically important coding agents.

→ http://arxiv.org/abs/2611.08417v1

## 4. Measured Coupling for Parallel Decoding in Diffusion Language Models
*Relevance: 221%*

This paper solves the problem of efficiently deciding which tokens can be safely generated together in parallel diffusion language models, replacing the indirect mean-field proxy (which penalizes similar-looking predictions) with direct measurement of how committing one token affects confidence at other positions using cheap probes during the forward pass. For ML practitioners, this coupling-based approach requires fewer decoding steps than mean-field methods across multiple benchmarks, offers faster inference in most settings without additional training or auxiliary models, and integrates seamlessly with existing decoding frameworks including key-value caching.

→ http://arxiv.org/abs/2611.08307v1

## 5. AutoCompress: Automated Hardware-Guided Model Compression
*Relevance: 221%*

AutoCompress solves the problem of LLM pruning workflows that target parameter counts rather than actual hardware constraints (latency, throughput, memory), which fail to account for how these metrics vary across architectures, workloads, and hardware. The method uses differentiable architecture search that directly incorporates hardware-specific constraints, enabling automated model compression that meets real deployment requirements without manual trial-and-error tuning—making it valuable for ML practitioners who need to deploy efficient models on specific hardware configurations.

→ http://arxiv.org/abs/2611.08290v1
