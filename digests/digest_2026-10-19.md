## 1. FuTransformer: FP8 prefill and INT4 decode for Llama-style inference on Hopper
*Relevance: 260%*

**Summary:**

FuTransformer addresses the efficiency bottleneck in LLM inference by using FP8 precision during prefill (compute-bound) and INT4 for decode (memory-bound), implementing optimized CUDA kernels for Hopper GPUs with techniques like direct KV-cache placement and fused operations. This matters to ML practitioners because it demonstrates how phase-specific quantization and hardware-aware optimizations can significantly reduce memory bandwidth requirements and improve inference throughput for Llama-style models on modern NVIDIA hardware.

→ http://arxiv.org/abs/2610.23796v1

## 2. Tool Recommendation for Multi-Step Agents: Finding Every Tool a Task Needs
*Relevance: 250%*

**Summary:**

This paper solves the problem of tool discovery for multi-step agents when thousands of available tools exceed LLM context windows, causing task failures when needed tools are missing. The authors deploy a Tool Recommendation system that provides access to ~8,200 tools through just three fixed interface tools at the agent-gateway level, enabling agents to dynamically discover and use hundreds of times more tools than typical MCP servers expose while maintaining user credential security and consent checks.

→ http://arxiv.org/abs/2610.23707v1

## 3. Self-Building Labs
*Relevance: 227%*

**Summary:**

This paper addresses the bottleneck of laboratory inflexibility in self-driving laboratories by introducing Self-Building Labs (SBLs)—AI systems that autonomously design, configure, and operate laboratory setups from scratch given only high-level scientific goals. For ML practitioners, this represents a significant advance in autonomous AI agents capable of end-to-end physical world manipulation, extending beyond experiment optimization to full laboratory infrastructure creation, potentially accelerating automated scientific discovery pipelines.

→ http://arxiv.org/abs/2610.23826v1

## 4. Behavioral Couplings: From Formation to Behavioral Emergence in Language Models
*Relevance: 226%*

**Summary:** This paper addresses the problem of unintended behavioral side effects during LLM fine-tuning, where training for one behavior (e.g., warmth) inadvertently induces another (e.g., sycophancy)—termed "behavioral couplings." The authors investigate how these couplings form through co-occurrence in training data and study their properties, which matters to ML practitioners because it reveals hidden risks in fine-tuning pipelines and highlights the need for careful consideration of behavioral dependencies when aligning or customizing language models.

→ http://arxiv.org/abs/2610.23847v1

## 5. DrugHarness: An Evolvable Agent Harness for Computational Drug Discovery
*Relevance: 220%*

**Summary:** DrugHarness addresses the challenge of building adaptive AI agents for computational drug discovery by introducing an evolvable harness that combines composable scientific operations (80+) with conditional skill induction, learning action hypotheses from execution trajectories and outcome feedback. This matters to ML practitioners because it demonstrates a framework for agents that can dynamically adapt their behavior based on evidence while maintaining transparent, traceable reasoning across complex multi-step scientific workflows.

→ http://arxiv.org/abs/2610.23791v1
