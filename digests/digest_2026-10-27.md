## 1. Pretraining Knows What, Simulation Teaches How: Compositional Generalization in a Sim-Trained Robot Agent
*Relevance: 273%*

ZAP solves the challenge of achieving robust real-world robot control without any real-world training data by combining a pretrained vision-language model (for task understanding) with simulation-based fine-tuning using supervised learning and GRPO (for motor control skills). This matters to ML practitioners because it demonstrates that compositional generalization—leveraging pretrained knowledge for "what" while learning "how" purely in simulation—can achieve 96.7% real-world success, offering a practical recipe for sim-to-real transfer without costly real-world data collection.

→ http://arxiv.org/abs/2610.35817v1

## 2. Free to Look, Free to Reason: Simple LLM Harnesses Outdiagnose Hand-Crafted Root Cause Analysis Agents
*Relevance: 226%*

**Summary:**

This paper addresses the problem of whether complex, hand-crafted LLM agents for microservice root cause analysis actually outperform simpler approaches, finding that minimal "harnesses" (single-call evidence packages, SQL agents, or coding agents) match or exceed five published specialized RCA agents on a standardized benchmark. For ML practitioners, this matters because it suggests that investing in elaborate agent architectures with fixed procedures and role-based designs may be unnecessary—capable foundation models with simple interfaces can achieve comparable diagnostic performance with less engineering overhead.

→ http://arxiv.org/abs/2610.35767v1

## 3. I-HITL: Inalienable Human-in-the-Loop
*Relevance: 225%*

**Summary:**

This paper addresses the problem of ensuring AI agents cannot bypass human oversight mechanisms, even when the agent has compromised local systems that humans use for approval. The authors introduce "inalienable human-in-the-loop" (I-HITL) protocols that cryptographically guarantee agents can only initiate critical actions with explicit human approval, which matters to ML practitioners because it provides a robust safety framework for deploying increasingly capable autonomous agents that might otherwise circumvent traditional guardrails.

→ http://arxiv.org/abs/2610.35835v1

## 4. Retriever-Free Retrieval: Navigating Documents with Decision Models
*Relevance: 224%*

**Summary:**

DecisionRAG addresses the capability gap between advanced language models and traditional retrievers (which rely on lexical matching or fixed embeddings) by using decision models that jointly evaluate candidate document branches in a single forward pass without token generation. This matters to ML practitioners because it enables retrieval systems to leverage the full reasoning capabilities of pretrained language models, potentially eliminating cases where weak retrieval prevents strong generators from accessing relevant information.

→ http://arxiv.org/abs/2610.35868v1

## 5. Selective Tie Learning: Mitigating Spurious Correlations in Preference Optimization
*Relevance: 221%*

**Summary:** This paper addresses the problem of spurious correlations in preference optimization by selectively augmenting training data with "ties" (equally preferred responses), deriving a method to identify which ties most effectively reduce spurious reliance based on their predicted influence for log-linear policies. For ML practitioners, this offers a principled, first-order optimal approach to curate preference data that improves model robustness without requiring exhaustive data augmentation.

→ http://arxiv.org/abs/2610.35787v1
