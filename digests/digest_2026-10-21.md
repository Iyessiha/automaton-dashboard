## 1. Beyond 4 bits: Data-Centric Post-training Quantization and Recovery
*Relevance: 253%*

This paper addresses the failure of post-training quantization at extreme compression levels (2-bit), identifying that quantization representation, calibration data, and recovery fine-tuning data—often overlooked at 4-bit—become critical factors, with vector codebooks proving essential for restoring model quality. For ML practitioners, this work provides actionable guidance for achieving aggressive model compression beyond the typical 4-bit threshold, enabling deployment of large models (3.8B-32B parameters) in more resource-constrained environments.

→ http://arxiv.org/abs/2610.28537v1

## 2. Large Flow Language Models
*Relevance: 246%*

**Summary:**

This paper addresses the challenge of scaling continuous flow language models to billion-parameter sizes, presenting Lafa, an 8B parameter flow model that enables parallel text generation with better control and acceleration than discrete diffusion approaches. The method uses blockwise flow modeling with causal attention on prefixes and bidirectional flow within blocks, allowing efficient adaptation from pretrained autoregressive models—offering ML practitioners a data-efficient path to build fast, controllable generative language models beyond traditional sequential decoding.

→ http://arxiv.org/abs/2610.28559v1

## 3. Beyond the Sequentiality Bottleneck: A Hybrid Diffusion-Autoregressive Framework for Efficient Multimodal Reasoning
*Relevance: 238%*

This paper addresses the sequentiality bottleneck in autoregressive reasoning models and the semantic coherence issues in diffusion language models by proposing CoRAL, a hybrid framework where a diffusion-based Planner generates multiple diverse reasoning trajectories in parallel while a larger autoregressive Executor selects and synthesizes the final answer. For ML practitioners, this matters because it combines the parallel efficiency of diffusion models with the coherent generation of autoregressive models, potentially enabling faster and more effective multimodal reasoning without sacrificing output quality.

→ http://arxiv.org/abs/2610.28584v1

## 4. Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition
*Relevance: 233%*

Sage-A1.5 is a 35B Mixture-of-Experts model that advances long-horizon problem solving through adaptive capability composition, featuring agentic orchestration with task delegation and parallel subagent collaboration, built-in verification mechanisms, and open scientific discovery capabilities. This matters to ML practitioners because it demonstrates how to scale beyond single-agent execution to handle complex, multi-step tasks by dynamically organizing work and revising approaches during execution—a key challenge in building reliable autonomous AI systems.

→ http://arxiv.org/abs/2610.28578v1

## 5. The Token-Energy Law of LLM Decode: Active Bytes and Realized Time Account for Joules per Token
*Relevance: 232%*

This paper addresses the problem of understanding and predicting GPU energy consumption per token during LLM inference, which is critical for efficient deployment. The authors propose the Token-Energy Law, an interpretable model that predicts energy per token using two key factors: "active bytes" (combining model weights and per-request KV cache memory demands) and "realized decode time."

For ML practitioners, this matters because it provides a principled framework to estimate and optimize energy costs across different model architectures, hardware configurations, and serving settings—enabling more sustainable and cost-effective LLM deployment decisions.

→ http://arxiv.org/abs/2610.28576v1
