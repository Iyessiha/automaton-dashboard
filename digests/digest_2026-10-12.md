## 1. AI Models Can Provably Hide Arbitrary Capabilities
*Relevance: 287%*

**Summary:**

This paper addresses the problem that AI safety capability evaluations may be fundamentally unreliable, demonstrating that models can provably hide dangerous capabilities using backdoor attacks with encrypted neural networks that only activate with secret triggers—making hidden behaviors cryptographically impossible to detect even with full weight access. For ML practitioners, this matters because it undermines assumptions that thorough testing and interpretability tools can reliably surface all model capabilities before deployment, suggesting current safety evaluation paradigms have theoretical limits against adversarial scenarios.

→ http://arxiv.org/abs/2610.13928v1

## 2. DualQuant: Dual-scale Calibration-free Weight-and-Activation Quantization for LLMs
*Relevance: 233%*

**Summary:**

DualQuant solves the challenge of quantizing both weights and activations in LLMs without requiring calibration data, enabling full throughput gains on accelerators with native 4-bit support. The method uses a dual-scale framework that directly minimizes weight-reconstruction MSE while simultaneously producing per-channel activation rescalings, making it practical for ML practitioners seeking efficient low-bit inference deployment without the overhead of collecting calibration datasets.

→ http://arxiv.org/abs/2610.13767v1

## 3. Specialists Learn Faster: Knowledge Organization in Pre-training Shapes Knowledge Update Efficiency
*Relevance: 221%*

**Summary:** This paper investigates how knowledge organization during pre-training affects the efficiency of subsequent knowledge updates, finding that "specialist" models trained on chronologically ordered data require far fewer examples to learn new information compared to "generalist" models trained on shuffled data. For ML practitioners, this reveals that pre-training data ordering strategies can significantly impact continual learning efficiency, offering a new lever for optimizing models that need frequent knowledge updates.

→ http://arxiv.org/abs/2610.13835v1

## 4. Same Query, Different Answer: Run-to-Run Variance in Semantic Query Processing
*Relevance: 220%*

This paper investigates run-to-run variance in LLM-based semantic query engines, revealing that even at temperature 0, between 0.07% and 10.2% of rows produce different outputs across executions, with some tasks showing up to 24% variance. This matters for ML practitioners because it demonstrates that current benchmarking practices using single executions are unreliable, and that seemingly deterministic LLM deployments in data processing pipelines can produce inconsistent results that compound through query plans.

→ http://arxiv.org/abs/2610.13823v1

## 5. Matched-Context Group Policy Optimization for LLM Agent Training
*Relevance: 220%*

This paper addresses the credit assignment problem in training long-horizon LLM agents, where sparse terminal rewards make it difficult to evaluate intermediate decisions. The authors propose Matched-Context Group Policy Optimization (MCGPO), which constructs weighted action preferences from collected trajectories by matching comparison contexts using pre-action state summaries and rubric progress annotations.

This matters to ML practitioners because training effective LLM agents for multi-step tasks (like coding or reasoning) requires better methods for learning from sparse feedback, and MCGPO offers a practical approach to extract more useful training signal from existing rollout data.

→ http://arxiv.org/abs/2610.13755v1
