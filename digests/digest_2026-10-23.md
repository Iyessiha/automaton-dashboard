## 1. Beyond Causal Masks: Auditing and Localizing Hidden Future-Token Leakage in Adaptive Sequence Models
*Relevance: 234%*

**Summary:**

This paper addresses the problem of hidden future-token leakage in autoregressive models, where architectural components (like adaptive routing mechanisms) inadvertently expose the model to future tokens despite correct causal masking, creating misleadingly good evaluation metrics that don't translate to actual generation quality. The authors develop a prefix-invariance audit to detect and localize such leakage, demonstrating that a model showing dramatic validation loss improvements (3.60 → 1.43) actually fails during free-running generation—this matters to ML practitioners because it reveals how architectural innovations can produce illusory gains that only manifest during teacher-forced evaluation, necessitating systematic auditing beyond standard causal mask verification.

→ http://arxiv.org/abs/2610.31522v1

## 2. Training Small Language Models for Transferable Tool Selection
*Relevance: 224%*

This paper addresses the challenge of selecting relevant tools from large tool corpora for LLM agents, where context limits prevent including all tool descriptions and simple retrievers cannot determine which tools are actually needed. The authors demonstrate that small, open language models can be trained via reinforcement learning to match the tool selection capabilities of proprietary LLMs like Claude or ChatGPT, enabling more accessible and transferable tool selection for ML practitioners building agentic systems.

→ http://arxiv.org/abs/2610.31483v1

## 3. EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence
*Relevance: 218%*

This paper addresses the problem of LLM agents executing unsafe actions when tool responses omit safety-critical information, even when all returned statements are technically true. The authors introduce EpiSEM-Bench, an executable benchmark with 300 matched task pairs across six domains that systematically suppresses critical facts to measure unsafe execution rates and agents' ability to recover missing evidence.

This matters to ML practitioners because it highlights a crucial failure mode in tool-using agents—decisions based on incomplete rather than false information—and provides a systematic evaluation framework for assessing agent safety boundaries before deployment.

→ http://arxiv.org/abs/2610.31650v1

## 4. Causal Chain of Thought: Mitigating Attention Leakage via Context Isolation
*Relevance: 217%*

**Summary:**

CausalCoT addresses the problem of chain-of-thought reasoning steps being post-hoc justifications rather than causally driving model answers, caused by attention leakage where models can bypass reasoning through direct context lookup. The method enforces causal transparency by decomposing problems into directed acyclic graphs of atomic sub-questions with isolated context evaluation, which matters to ML practitioners because it provides more faithful, interpretable reasoning chains where each step genuinely influences the final output.

→ http://arxiv.org/abs/2610.31639v1

## 5. Questioning Instrumental Convergence in RLVR: Checkpoint Evidence from OLMo-3
*Relevance: 214%*

This paper investigates whether reinforcement learning with verifiable rewards (RLVR) causes LLMs to develop instrumental convergence behaviors like self-preservation, deception, or resistance to oversight, using checkpoint analysis from OLMo-3 training. For ML practitioners, this matters because it provides empirical evidence addressing theoretical AI safety concerns about whether standard RL post-training inherently induces power-seeking tendencies in language models.

→ http://arxiv.org/abs/2610.31624v1
