## 1. A team of Gemini 4 Argon agents beats Minecraft
*Relevance: 254%*

This paper demonstrates that a team of four Gemini 4 Argon agents can autonomously coordinate to defeat Minecraft's Ender Dragon by planning, writing, and debugging 2,783 programs themselves without human-assigned roles or game logic. This matters to ML practitioners because it showcases emergent multi-agent collaboration through natural language coordination (in-game chat and shared memory), suggesting that foundation models can self-organize for complex, long-horizon tasks requiring tool use and teamwork.

→ http://arxiv.org/abs/2610.22319v1

## 2. Shortcut Sensitivity in Agent-Safety Evaluations
*Relevance: 234%*

**Summary:**

This paper addresses the problem that AI safety guard evaluations can be unreliable due to shortcut cues in evaluation data that make labels predictable without actually measuring safety constructs. The authors introduce a three-level shortcut-auditing framework to systematically detect when guards exploit superficial patterns rather than genuine safety signals, which matters to ML practitioners because it helps ensure that deployed agent supervision systems are evaluated on meaningful safety criteria rather than spurious correlations.

→ http://arxiv.org/abs/2610.22243v1

## 3. Private Retrieval Augmented Generation via Random Projection
*Relevance: 229%*

**Summary:**

This paper addresses the privacy risk of sensitive data leakage from retrieval datastores in RAG systems, proposing a solution using random projection applied to both datastore and query embeddings. This simple method provably preserves semantic similarity for effective retrieval while significantly reducing data extraction attacks—offering ML practitioners a practical, mathematically-grounded approach to deploy RAG systems with stronger privacy guarantees without sacrificing retrieval quality.

→ http://arxiv.org/abs/2610.22297v1

## 4. BitSparse: Compact Activation Storage for ReLU Feed-Forward Networks
*Relevance: 228%*

BitSparse solves the memory bottleneck of storing activations during LLM training by introducing a GPU-resident lossless compression format that exploits the natural sparsity of ReLU activations, using custom Triton kernels fused into autograd for efficient compression and exact reconstruction. This matters to ML practitioners because it offers a third path between costly recomputation (checkpointing) and lossy compression—enabling reduced memory footprint without sacrificing gradient accuracy, particularly relevant as sparse ReLU activations regain popularity in modern architectures.

→ http://arxiv.org/abs/2610.22256v1

## 5. OS-Helix: Unifying GUI Interaction and Code Execution in Native Computer-Using Agents
*Relevance: 226%*

This paper addresses the problem that desktop automation agents fail when naively combining GUI interaction with code execution, as simple tool composition degrades performance rather than improving it. The authors present OS-Helix, an end-to-end trained multimodal agent that unifies GUI actions and code execution into a single action space, learning proper routing between modalities through training on hybrid data rather than prompt-level composition—this matters to ML practitioners because it demonstrates that effective computer-using agents require internalized coordination learned during training, not just tool access.

→ http://arxiv.org/abs/2610.22234v1
