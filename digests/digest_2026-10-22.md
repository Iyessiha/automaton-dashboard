## 1. Differentially Private Sparse Reward Estimation with Preference Feedback
*Relevance: 247%*

This paper addresses the challenge of protecting user privacy in RLHF alignment while avoiding estimation errors that scale poorly with large model dimensions, proposing a differentially private method that exploits sparse reward parameterizations to achieve bounds dependent on sparsity rather than full model size. For ML practitioners, this matters because it enables privacy-preserving human preference learning in overparameterized LLMs where existing dense DP methods become computationally prohibitive, making private alignment more practical at scale.

→ http://arxiv.org/abs/2610.30099v1

## 2. EPIC: Rethinking Trust Regions for Autoregressive LLM Policies via Exact-KL Prefix Importance-Ratio Clipping
*Relevance: 236%*

EPIC addresses the problem that standard PPO token-level clipping fails to properly measure policy change in autoregressive LLMs because it ignores how the prefix context itself is generated by the policy, causing issues in long-response and off-policy training scenarios. The method reformulates autoregressive generation as a finite-horizon MDP and derives an exact-KL prefix importance-ratio clipping approach that properly accounts for the full trajectory, which matters to ML practitioners because it provides more principled trust regions for RLHF-style training that should improve stability and performance when fine-tuning LLMs for reasoning tasks.

→ http://arxiv.org/abs/2610.29999v1

## 3. LongZero: Enhancing Long-Context Reasoning in LLMs from Zero Data
*Relevance: 226%*

**Summary:**

LongZero addresses the challenge of training LLMs for long-context reasoning without requiring expensive human-annotated data, scarce natural data, or stronger teacher models by introducing a self-play reinforcement learning approach where models generate and learn from their own proposed tasks. This matters to ML practitioners because it enables scalable, data-efficient improvement of long-context reasoning capabilities in LLMs without external dependencies, offering a practical path to enhance model performance as systems become increasingly powerful and traditional data sources become insufficient.

→ http://arxiv.org/abs/2610.30132v1

## 4. Agent Behavior Maps: Locating Agents by What They Would Do, Without Running Them
*Relevance: 220%*

**Summary:** This paper addresses the problem of comparing LLM agent behaviors without expensive environment rollouts by introducing Agent Behavior Maps, which represent agents using centered action log-likelihoods computed on shared reference trajectories. For ML practitioners, this method enables efficient behavioral comparison and performance prediction across diverse LLM-harness combinations, with theoretical error bounds and empirical validation showing coordinate distances reliably track trajectory KL divergence.

→ http://arxiv.org/abs/2610.30014v1

## 5. Multimodal Embodied Agents: A Unified Capability-centric Perspective from Computer-Use to Robot-Use
*Relevance: 214%*

This paper addresses the challenge of understanding what capabilities change when multimodal AI agents transition from digital computer-use tasks to physical robot-use scenarios. The authors introduce PAPAV, a unified capability-centric framework that identifies five recurring functions needed for multimodal embodied agents, providing ML practitioners with a structured way to analyze, compare, and develop agents that must integrate reasoning, perception, and physical action across both virtual and robotic domains.

→ http://arxiv.org/abs/2610.30108v1
