## 1. FrontierPhysics: Evaluating Agents for End-to-End Physics Research
*Relevance: 227%*

FrontierPhysics addresses the lack of comprehensive benchmarks for evaluating AI agents on complete physics research workflows, introducing 56 expert-created tasks spanning nine domains that require agents to perform end-to-end research including literature review, planning, experimentation, and structured output generation. This matters to ML practitioners because it provides a rigorous evaluation framework that tests agents on realistic, multi-step scientific reasoning rather than isolated sub-tasks, enabling better assessment of AI systems designed for autonomous research assistance.

→ http://arxiv.org/abs/2611.06910v1

## 2. Context--Answer Metamodels: Forecasting LLM Activations Before the First Answer Token
*Relevance: 223%*

This paper addresses the costly problem of characterizing the variation in LLM outputs under stochastic decoding, which typically requires many expensive autoregressive rollouts. The authors train "context-answer metamodels" that predict answer activations directly from context activations before generating any tokens, enabling efficient forecasting of model behavior.

This matters to ML practitioners because it could significantly reduce computational costs when analyzing LLM output distributions, enabling faster uncertainty estimation and model behavior characterization without running multiple full generations.

→ http://arxiv.org/abs/2611.06837v1

## 3. Visual Token Routing: Learning to keep tokens that matter
*Relevance: 217%*

**Summary:**

This paper addresses the computational bottleneck of computer-use agents processing thousands of visual tokens per screenshot, which creates prohibitively long contexts during extended tasks. The authors introduce Visual Token Routing, a method that identifies and removes semantically irrelevant or temporally redundant visual tokens, significantly reducing computational costs while maintaining agent performance—enabling ML practitioners to deploy vision-language agents more efficiently in long-horizon and real-time applications.

→ http://arxiv.org/abs/2611.06854v1

## 4. Alignment Myopia in Generative AI
*Relevance: 215%*

**Summary:**

This paper identifies the problem that current AI alignment methods focus too narrowly on immediate user satisfaction, ignoring long-term harms from sustained human-AI interaction such as cognitive decline and reduced autonomy. The authors propose shifting toward long-horizon alignment that considers how AI impacts users over time, which matters to ML practitioners because it challenges them to develop feedback mechanisms and evaluation metrics that account for cumulative effects rather than just per-interaction performance.

→ http://arxiv.org/abs/2611.06830v1

## 5. Route First, See Later: Enabling Vision Agents to Reason Scientifically by Separating Routing Policy from Action Spaces
*Relevance: 212%*

ZETA solves the problem of unreliable multi-tool vision agents in scientific workflows by decoupling routing decisions (selecting which tool to use) from visual execution (running the tool), enabling practitioners to diagnose whether failures stem from flawed reasoning or perception errors. This separation matters to ML practitioners because it provides auditability and reliability critical for high-stakes scientific automation, allowing systematic debugging and extension of vision agent capabilities.

→ http://arxiv.org/abs/2611.06760v1
