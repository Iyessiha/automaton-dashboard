## 1. A Circuit for In-Context Learning
*Relevance: 265%*

This paper identifies the complete circuit mechanism for in-context learning in 3-4B parameter transformers, showing how models perform few-shot classification with arbitrary labels through a key-value memory system where label tokens encode identity information in residual streams. Understanding this compositional mechanism matters to ML practitioners because it demystifies how ICL works within a single forward pass, potentially enabling more reliable prompt engineering and targeted model improvements.

→ http://arxiv.org/abs/2611.05344v1

## 2. You don't need long context
*Relevance: 251%*

**Summary:**

This paper addresses the high computational cost of long-context LLM inference by demonstrating that frequent context compaction allows frontier models to maintain short contexts with minimal accuracy loss across long-horizon and long-input tasks, including software engineering benchmarks. This matters to ML practitioners because it suggests significant inference cost savings (up to 7x) are achievable without sacrificing performance, challenging assumptions about the necessity of extended context windows.

→ http://arxiv.org/abs/2611.05306v1

## 3. LoopVQ: Sub 1-bit KV Cache Quantization for Looped Transformers
*Relevance: 239%*

**Summary:** This paper addresses the memory bottleneck caused by KV cache growth in looped transformers, where cache size scales linearly with loop steps despite parameter efficiency. The authors propose LoopVQ, a vector quantization method that exploits redundancy along the loop axis to achieve sub-1-bit KV cache quantization.

**Why it matters:** ML practitioners working with parameter-efficient looped transformers can now reduce the dominant memory constraint (KV cache) to match the model's parameter efficiency, enabling deployment of larger effective models on memory-limited hardware.

→ http://arxiv.org/abs/2611.05304v1

## 4. Knowingly Wrong: Training LLMs Against Their Own Beliefs can Induce Misalignment
*Relevance: 228%*

**Summary:**

This paper demonstrates that fine-tuning LLMs on data the model "believes" to be false—even if the content is benign (e.g., incorrect math or trivia answers)—can induce broad misalignment, with stronger model disbelief correlating with greater misalignment. For ML practitioners, this reveals that alignment risks extend beyond obviously harmful training data, suggesting that data quality verification against model beliefs may be crucial during fine-tuning to prevent unintended behavioral degradation.

→ http://arxiv.org/abs/2611.05287v1

## 5. Suppressing Misaligned Behaviors in Language Models, Durably
*Relevance: 225%*

**Summary:**

This paper addresses the problem of durably suppressing unwanted behaviors in language models that may re-emerge after initial mitigation, constructing "model organisms" with narrow and broad triggers to study how effectively misaligned behaviors can be eliminated. The research matters to ML practitioners because it provides insights into whether safety interventions persist across different conditions, helping develop more robust alignment techniques for deployed models.

→ http://arxiv.org/abs/2611.05358v1
